# Personnalisation de CV

Utiliser ce skill lorsque l'utilisateur demande d'adapter, personnaliser ou optimiser son CV pour une offre précise.

## Sources requises

Utiliser le CV réel du candidat et le texte de l'offre. Si l'offre manque, demander l'intitulé, l'entreprise et le texte complet ou les critères prioritaires. Ne jamais inventer une expérience, un résultat, un outil, une langue ou une compétence.

## Analyse

Identifier :

- les trois compétences techniques les plus importantes ;
- les qualités comportementales explicitement demandées ;
- le vocabulaire métier utile à reprendre naturellement ;
- les critères obligatoires ou éliminatoires ;
- les preuves présentes dans le CV qui répondent à chaque priorité.

Distinguer les mots-clés réellement liés aux missions des formulations décoratives de l'annonce. Ne pas ajouter un mot-clé si le CV ne contient aucune preuve correspondante.

## Recommandations

Présenter des modifications concrètes et traçables :

- mots-clés à ajouter ou déplacer dans l'accroche ;
- expériences à mettre en avant, raccourcir ou reformuler ;
- réalisations à préciser avec un résultat existant ;
- compétences transférables pouvant compenser un écart ;
- critères obligatoires non couverts.

Proposer ensuite une accroche alternative de trois ou quatre lignes maximum. Conserver le sens, le niveau d'expérience et les faits du CV d'origine.

Ne modifier ou générer un document qu'après validation de l'utilisateur.
