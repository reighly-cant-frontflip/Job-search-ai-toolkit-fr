# SKILL : Personnalisation de CV

> Fichier à uploader dans ton Project Claude.ai (« Add content »).
> Fait partie du toolkit : Assistant IA de Recherche d'Emploi.

## Déclencheur

L'utilisateur dit : « adapte mon CV pour cette offre », « personnalise mon CV », « optimise mon CV ».

## Processus à suivre

**Étape 1 — Collecte d'informations**

Si l'offre d'emploi n'est pas fournie, demander :
- L'intitulé exact du poste
- Le nom de l'entreprise
- Le texte complet de l'offre (ou les 5 mots-clés prioritaires)

**Étape 2 — Analyse de l'offre**

Identifier :
- Les 3 compétences techniques les plus demandées
- Les 2 qualités comportementales mentionnées
- Le vocabulaire spécifique utilisé (à réutiliser dans le CV)
- Les critères éliminatoires (langues, logiciels, expérience minimale)

**Étape 3 — Recommandations de personnalisation**

Produire une liste de modifications concrètes :
- Quels mots-clés ajouter ou déplacer dans l'accroche
- Quelle expérience mettre en avant ou reformuler
- Si une compétence manque, comment la compenser par une autre

**Étape 4 — Reformulation de l'accroche**

Proposer une version alternative du résumé de profil (3-4 lignes max), alignée sur l'offre.

## Contraintes

- Ne pas inventer de compétences ou d'expériences
- Toujours partir du CV réel fourni dans le Project
- Signaler clairement si un critère obligatoire de l'offre n'est pas couvert
